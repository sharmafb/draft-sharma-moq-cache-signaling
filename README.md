* [Original MOQT Issue](https://github.com/moq-wg/moq-transport/issues/1907)

## Building the Draft

Formatted text and HTML versions of the draft can be built with:

```sh
make
```

Local builds require the software described in the
[i-d-template setup instructions](https://github.com/martinthomson/i-d-template/blob/main/doc/SETUP.md).
